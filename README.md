
Hobnob Bakery Website

A responsive bakery website built using HTML5, CSS3, and JavaScript.

How to Run

Double-click index.html to open it in a browser. No server setup or installation required.

Folder Structure

• index.html - Page structure
• css/style.css - Design styles and responsive media queries
• js/data.js - Array of objects containing products, categories, and banner slides
• js/script.js - Logic for cards, search, popups, cart count, and the banner
• img/ - Directory for all image assets
